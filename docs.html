V1 支付接口文档

通过 HTTP POST 请求发起支付，采用标准 MD5 签名机制。

发起支付

接口地址： https://api.lynli.me/mapi.php

请求参数：

  • pid - 商户ID (必填)
  • type - 支付类型，固定为 alipay (必填)
  • out_trade_no - 商户订单号 (必填)
  • money - 金额 (必填)
  • sign - MD5签名 (必填)

MD5 签名规则

sign = md5(按参数名ASCII码从小到大排序后的 a=b&c=d 格式 + 商户密钥)
