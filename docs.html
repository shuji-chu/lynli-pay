支付网关接口文档（V1）

标准 HTTP + MD5 签名机制。所有接口基础地址：https://api.lynli.me/api/v1

① 发起支付（下单）

接口地址： POST /api/v1/payplat/gateway/submit（JSON）

请求参数：

  • app_id - 商户标识（必填，商户中心获取）
  • out_trade_no - 商户侧唯一订单号（必填）
  • amount - 金额（元），两位小数（必填）
  • name - 商品名称（选填，收银台展示）
  • method - 支付方式：alipay（默认）/ usdt
  • notify_url - 异步通知地址（选填）
  • timestamp - 秒级时间戳（必填）
  • sign - MD5 签名（必填）

签名规则：剔除 sign 与空值参数，其余按参数名 ASCII 升序拼成 k1=v1&k2=v2&…，末尾直接拼接 app_secret（无 &），整体 MD5，32 位小写。

raw = "amount=100.00&app_id=QTxxx&name=订单&out_trade_no=M1001&timestamp=1735689600" + app_secret
sign = md5(raw) // 32 位小写

返回：{ "code": 0, "trade_no": "PAY17xxxx", "amount": "100.00", "payurl": "https://…", "qrcode": "https://…" }

拿到 trade_no 后引导用户打开收银台：cashier.html?trade_no=PAY17xxxx

② 查单接口

接口地址： GET /api/v1/payplat/gateway/query?app_id=&trade_no=&timestamp=&sign=

返回 status：0 待支付 · 2 已支付已结算；fee 为平台抽成，credit 为商户入账。

③ 异步回调通知

支付成功后，平台以 POST form-urlencoded 请求你下单传入的 notify_url：

out_trade_no=M1001&trade_no=PAY17xxxx&amount=100.00&status=TRADE_SUCCESS&timestamp=1735689660&sign=…
  • 签名规则与请求一致，请务必验签后处理业务；
  • 收到通知请返回 HTTP 200；失败自动重试最多 3 次；
  • 通知可能重复，请按订单状态做幂等处理。

④ 费率与结算

  • 手续费 = 订单金额 × 10%，支付到账即结算；
  • 商户余额 = 累计入账（90%）− 已提现金额；
  • 提现在商户中心「提现申请」发起，平台审核打款；被拒金额自动退回余额。
